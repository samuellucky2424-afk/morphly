# v2.5.15 — VB-CABLE installation and detection

Fixes the omitted VB-CABLE changes from v2.5.14. Morphly and its Windows installer now check Windows audio-driver registrations instead of the nonexistent VB-Audio InstallDir registry value. A healthy cable skips installation; accepting UAC or a successful installer exit alone no longer counts as verified installation.

The app captures setup exit codes, handles cancellation/timeouts/reboot requirements, and checks driver registration after installation. Concurrent install requests share one operation. Detection errors remain distinct from a missing driver.

The install button explains administrator approval and verification delays. Success asks the user to fully quit and reopen Morphly because the resident audio engine caches endpoints; reboot-required results explicitly ask for a Windows restart. Errors persist beside the button instead of being erased by background status polling. Installation is disabled during active voice conversion.

Release checks verify that both the detection module and PowerShell probe are packaged. Regression tests cover absent, healthy, broken, duplicate, rebooting and unqueryable drivers, as well as setup failures and false-success prevention. The probe detects this development laptop's healthy cable without changing drivers. The other laptop's installation and audio routing have not been tested remotely.

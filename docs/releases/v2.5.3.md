# Morphly Desktop 2.5.3

This patch fixes the dashboard layout when the app is resized or used on a smaller screen.

- Voice settings and pitch presets fit inside the panel without clipping.
- Long microphone and output-device names stay contained; dropdown options wrap.
- Streaming controls wrap when space is limited.
- Narrow screens stack the voice panel and preview. Short windows allow scrolling to every control.
- Compact and touch layouts provide larger control targets.

Validation: TypeScript checks and all 145 Node regression tests passed for the release source. Two existing integration checks were updated to recognize the responsive workspace and its CSS. An isolated browser fixture using the real dashboard components passed layout checks at 320x568, 375x812, 768x1024, 1024x768, 1920x1080 and 844x390, including pitch controls and device-dropdown bounds. These checks used simulated devices and do not certify live camera or audio behavior.

The reported WhatsApp virtual-camera problem remains under investigation; this patch does not change the native camera implementation.

The `v2.5.3` tag triggers the Windows release workflow. After its tests, build and artifact checks pass, it publishes `Morphly-Setup-2.5.3.exe` and `latest.yml` to the GitHub release for direct installation and the desktop updater.

Browser/retry follow-up: https://morphly-71ud6ewy0-lus-projects-b2662b64.vercel.app. The user reports Chrome works (Vidu and AliRTC HTTP 101), while Edge repeatedly fails. This is evidence of a browser-specific factor, not proof of the particular privacy setting or extension responsible. The old six-issued-sessions/ten-minute gate could turn post-issuance browser failures into long application cooldowns. Review now uses six starts/minute plus thirty/ten minutes, calculated from durable issuance timestamps, exact Retry-After and SESSION_START_RATE_LIMIT. Frontend preserves that error rather than rewriting it as a generic network/provider error. Exhausted Edge signaling attempts recommend Chrome or Decart and carry VIDU_SIGNALING_UNREACHABLE. No browser security settings, regions, production deployment or desktop release were changed. All 236 tests and TypeScript checks passed. Browser compatibility remains to be tested; this is not a verified resolution of the Edge block.
